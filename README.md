# 가위닥터 사사끼

30년 경력의 가위 연마 장인 김태희와 약 1,000명의 고객을 중심으로, 정밀 연마·날 복원·미용 및 애견 가위 수리·A/S를 소개하는 심플한 Next.js 웹사이트.

대표 김태희의 전화 상담 및 네이버 블로그 연결 버튼을 제공합니다.

모바일에서는 하단에 접수 안내 및 전화 상담(010-6564-4992) 버튼이 고정됩니다. 수리 접수는 전화 상담 → 가위 발송 → 상태·비용 안내 → 수리·반송의 4단계로 안내합니다.

로고, 메뉴, 서비스 카드, 접수 단계, 상담 번호에는 가을 색상의 선형 SVG 아이콘을 사용합니다. 아이콘은 `app/components/ui-icon.jsx`에서 관리하며 텍스트 라벨을 함께 제공합니다.

왼쪽 상단의 `public/images/scissor-doctor-brand.svg`는 사용자 명함의 S·가위 문양과 가위닥터 글자를 참고해 웹용으로 다시 그린 로고입니다. PC에서는 메뉴를 오른쪽에, 모바일에서는 메뉴를 로고 다음 줄에 표시합니다.

사용자가 제공한 사업자등록증과 명함을 기준으로 하단 사업자 정보(상호, 대표자, 사업자등록번호, 사업장 주소, 업종, 상담 전화)를 표시합니다. 기본 상담 번호는 010-6564-4992이며 010-9644-4689도 함께 안내합니다.

택배 접수, 미용학원 등 대량 수리 할인, 불만족 시 100% 환불 안내를 포함합니다. 가위 구매·현장 출장 판매는 상담 안내에만 간단히 소개합니다.

내용 참고: https://blog.naver.com/kuh4689/222617975844

히어로는 3장의 광고 이미지를 배치한 스와이프형 슬라이더입니다. 6.5초 자동 재생, 정지·재생, 이전·다음, 광고 선택, 키보드 방향키 및 이미지 터치 스와이프를 지원합니다. 수동 조작 후 자동 재생이 멈추고, 마우스·키보드 포커스가 머무는 동안에도 일시 정지합니다. 움직임 줄이기 설정에서는 자동 재생과 전환 애니메이션을 끕니다.

이미지는 `public/images/hero-sharpening-autumn.png`, `hero-hair-autumn.png`, `hero-pet-autumn.png`이며 제작 프롬프트는 `docs/hero-ad-prompts.md`에 기록했습니다. 사용자 제공 인물 사진을 변환한 `scissor-doctor-portrait-autumn.png`는 장인 소개 영역에 배치했습니다.

서비스 카드에는 `scissor-sharpening-autumn.png`, `scissor-restoration-autumn.png`, `scissor-repair-autumn.png`를 사용합니다. 전체 화면은 크림·밤색·차분한 주황색으로 구성했습니다. 내장 이미지 생성 도구의 제작 프롬프트와 파일 정보는 `docs/autumn-image-prompts.md`에 기록했습니다.

## 실행

```sh
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 배포용 빌드

```sh
npm run build
npm start
```

브랜드 소개용 한 페이지이며 주문·결제 기능은 포함하지 않습니다.

## 겨울 테마

전체 화면은 눈빛 화이트·아이스 블루·네이비 색상을 사용합니다. 메인 광고와 서비스 카드에는 겨울 콘셉트의 `hero-sharpening-winter.png`, `hero-hair-winter.png`, `hero-pet-winter.png`를 사용합니다. 로고는 파란색 SD·가위 문양의 `scissor-doctor-logo.png`이며 브라우저 아이콘에도 적용했습니다.
